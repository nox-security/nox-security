# NOX Website v3.6 — Header Navigation Refinement

This revision is deliberately limited to the website header navigation, mobile dropdown menu and fixed mobile conversion bar.

## Desktop header

- Removed the separate Home item; the NOX logo remains linked to `/`.
- Reordered the main navigation to:
  - Commercial
  - Residential
  - Servicing & Monitoring
  - Case Studies
  - About NOX
  - Contact
- Added clean desktop dropdowns using existing website routes only.
- Commercial is split into understated Security and Fire & Compliance groups.
- No pages, URLs or metadata were changed.

## Mobile navigation

- Commercial, Residential and Servicing & Monitoring are collapsed accordions.
- Only one accordion opens at a time.
- The full heading row is clickable with a subtle chevron.
- Added a quick smooth open/close animation and reduced unnecessary divider lines.
- Mobile navigation height accounts for the fixed conversion bar.

## Fixed mobile conversion bar

- Updated wording to: Book a Free Survey | WhatsApp | Call.
