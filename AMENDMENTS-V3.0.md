# NOX Website v3.0 Amendments

## Direction retained

- Built from the approved v2.6 working base rather than redesigning the website from scratch.
- Preserved the premium black-and-white identity, principal homepage structure and established page layouts.
- Kept the site focused on a single high-value enquiry route: Request Your Free Security Survey.

## Navigation and customer segmentation

- Retained Home in desktop and mobile navigation.
- Kept Perimeter Protection available as a search and internal-link landing page, but not as a primary navigation item.
- Clarified the journey between Residential installations, Commercial installations and Service Plans.
- Positioned Residential around Ajax intruder alarms, CCTV, takeovers and ongoing aftercare for ordinary family homes as well as larger properties.
- Positioned Commercial around Fire alarm installation, Fire alarm servicing, emergency lighting, Fire risk assessments, CCTV, intruder systems and compliance support.

## Conversion improvements

- Kept the exact GoHighLevel Website Enquiry form on the quote and Contact pages.
- Preserved the mobile form-first order before phone, WhatsApp and email options.
- Added clearer related-service, case-study, review and local-service links so important pages are not dead ends.
- Continued to introduce monitoring, maintenance, takeovers and compliance packages naturally after installation content.

## Project proof and imagery

- Continued using genuine NOX project photography throughout the homepage, service pages and case studies.
- Retained the Bottle & Thyme, Tan Station, Retford former bank, Chesterfield residential, Dronfield industrial and other verified project stories.
- Improved homepage Ajax presentation by removing the least suitable NVR, kit and DoorBell background cards.
- Reworked the homepage Ajax product rail around MotionCam, KeyPad TouchScreen, Hub 2 Plus, DoorProtect, Curtain Outdoor and StreetSiren.
- Added a property-led Ajax video integration section using a real NOX installation image.
- Corrected selected image crops that contained screenshot controls or unnecessary black bars.
- Added a new 1200 × 630 NOX social-sharing image.

## SEO foundation

- Added a dedicated `/services` search landing-page hub.
- Added 14 unique high-intent service landing pages covering the principal Chesterfield, Sheffield and Derbyshire searches.
- Added unique titles, descriptions, H1 headings, FAQs, local wording, related services and relevant real case studies.
- Added Service, FAQ and Breadcrumb structured data where appropriate.
- Added visible breadcrumbs to system, plan, service and case-study pages.
- Added focused internal-link blocks from the homepage, Residential, Commercial, Systems and Service Plans pages.
- Expanded the sitemap to include the new landing-page network.
- Added local service links to the footer.

## Technical deployment correction

- Replaced all machine-specific package registry URLs in `package-lock.json` with public `registry.npmjs.org` URLs.
- Added `.npmrc` to explicitly use the public npm registry.
- Updated the project name and version to `nox-security-v3-marketing-system` version `3.0.0`.
- This specifically addresses the previous Vercel `EHOSTUNREACH` dependency-installation failure caused by an inaccessible internal package registry.

## Accuracy and compliance

- Retained the guardrails against police-response claims, URNs, Farsight branding, unsupported accreditation claims, guaranteed attendance, false-alarm guarantees and unconfirmed response-time promises.
- Kept verified project facts separate from unconfirmed outcomes or invented customer quotations.
